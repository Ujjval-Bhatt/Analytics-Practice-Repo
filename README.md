# Analytics-Practice-Repo

**Project Overview**
This project analyzes Bengaluru rental properties to help tenants identify affordable localities based on rent budget, seller type, property size, and family requirements.


**Business Problem**

House hunters often struggle to identify which Bengaluru localities offer the best value for money. This project aims to compare rental prices, seller types, and property characteristics to support better rental decisions.

**Tools Used**

    Python
    SQL
    Power BI

**Dataset**

| Column        | Description           |
| ------------- | --------------------- |
| Seller Type   | Owner, Agent, Builder |
| Bedroom       | Number of Bedrooms    |
| Layout Type   | BHK, RK               |
| Property Type | Apartment, House etc  |
| Locality      | Property Location     |
| Price         | Monthly Rent          |
| Area          | Square Feet           |
| Bathrooms     | Number of Bathrooms   |
